# 📕 Examen Parcial de Certificación (Módulos 1 al 5)

¡Llegó el momento de poner a prueba tus conocimientos en un entorno controlado!

## Parámetros de Evaluación (0 a 100 Puntos)

-   Arquitectura de WebComponents (30 pts): Correcto uso de Custom Elements, Shadow DOM, `<template> y <slot>`.
-   Clean Code & Encapsulamiento (30 pts): Nombres de atributos, separación de responsabilidades y estilos con adoptedStyleSheets.
-   Reactividad & Eventos (20 pts): Emisión unidireccional de CustomEvent con composed: true sin antipatrones.
-   Gestión de Memoria (20 pts): Limpieza explícita de listeners y temporizadores en disconnectedCallback().
